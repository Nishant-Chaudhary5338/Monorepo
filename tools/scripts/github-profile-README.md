## What I build

**Component systems and libraries** — authored `@repo/dashcraft` (headless React dashboard library) and `@repo/present` (Prezi-style React presentation engine). Designed the API surface, state architecture, and plugin model from scratch.

**Monorepo infrastructure** — architected a Turborepo monorepo with 14 apps, 8 shared packages, and 28 custom MCP servers for automated scaffolding, TypeScript enforcement, render profiling, and test generation. One command to scaffold, lint, and ship.

**AI-native tooling** — built an agentic job-application bot (Claude + Playwright + SQLite) and a prompt-to-dashboard UI generator (OpenAI SDK + Monaco editor + diff-patching). Integrating LLMs at the tool level, not just the feature level.

**Production UIs** — luxury hospitality sites, 3D portfolios, micro-frontend architecture, enterprise data tables. React 19, TypeScript strict, Three.js, GSAP, Framer Motion.
